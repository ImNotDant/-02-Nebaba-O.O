# Лабораторна робота №1 — Git та структура .NET-проєкту

* **ПІБ:** \[Небаба О.О]
* **Група:** \[401ТК]
* **Номер варіанта:** 4
* **Предметна область:** Cinema Booking (бронювання квитків у кінотеатрі)
* **Версія .NET:** 10

## Опис предметної області

Система Cinema Booking призначена для бронювання квитків на кіносеанси. Користувач може переглядати доступні сеанси та обирати місця в кінозалі. Інформація про фільми, сеанси й бронювання належить до предметної області системи. У межах цієї лабораторної роботи створено базову структуру .NET-рішення з окремими проєктами App і Domain.

## Структура проєкту

```text
ModernProgramming/
├── src/
│   ├── CinemaBooking.App/
│   └── CinemaBooking.Domain/
├── README.md
├── .gitignore
└── ModernProgramming.slnx
```

## Запуск

Потрібен встановлений .NET SDK 10.

```bash
dotnet run --project src/CinemaBooking.App
```
