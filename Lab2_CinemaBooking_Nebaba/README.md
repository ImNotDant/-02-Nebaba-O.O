# Лабораторна робота №2 — ООП та моделювання предметної області

- **ПІБ:** Небаба О.О.
- **Група:** 401ТК
- **Варіант:** 4
- **Предметна область:** Кінотеатр (Cinema Booking)
- **.NET:** 10

Система моделює продаж квитків на кіносеанси. Вона містить фільми, кінозали, сеанси та квитки. Сеанс контролює бронювання місць і не дозволяє продати одне місце двічі. Для розрахунку вартості квитка використовуються звичайна та студентська стратегії ціноутворення.

## Запуск
```bash
dotnet run --project src/CinemaBooking.App
```
